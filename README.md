# Alumni Connect – Smart Alumni Networking and Career Development Platform

Alumni Connect is a web-based platform designed to strengthen the relationship between educational institutions, alumni, students, faculty, and placement coordinators. The platform creates a centralized space where alumni can share their professional journey, students can explore career opportunities, and faculty can efficiently manage alumni engagement.

The system supports multiple user roles, including Students, Alumni, Faculty Administrators, Training & Placement (TPC) Faculty, and Forum Leads, each with dedicated dashboards and role-specific functionalities.

Students can search for alumni based on profession, company, skills, and interests to find mentors, career guidance, and networking opportunities. Alumni can build detailed professional profiles, share achievements, post updates, and contribute to the student community. Faculty members can review and approve registrations, manage users, moderate announcements, and oversee platform activities, while TPC Faculty can access alumni information to improve placement coordination. Forum Leads can publish department or club-related announcements and communicate with members.

The platform includes secure authentication, role-based access control, profile management, announcement and achievement posts, a community messaging system, and an intelligent alumni search feature. User passwords are securely stored using password hashing, and session management ensures authenticated access across the application.

Built using **Python (Flask)**, **SQLite**, **HTML**, **CSS**, and **JavaScript**, Alumni Connect provides a lightweight, scalable, and user-friendly solution for fostering long-term alumni engagement and improving collaboration between alumni and current students.

## Key Features

* Multi-role authentication and authorization
* Alumni profile creation and management
* Smart alumni search by profession, company, skills, and interests
* Faculty approval system for registrations
* Announcements and achievement posting
* Community discussion and messaging
* Training & Placement support dashboard
* Forum Lead management system
* Secure password hashing and session management
* Responsive and intuitive user interface

This project was developed as a **Final Year B.Tech Computer Science Engineering Mini Project** to demonstrate the practical application of full-stack web development, database management, authentication, and role-based access control in building a real-world alumni networking platform.
